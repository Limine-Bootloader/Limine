# Graphical-menu check assets

These assets are test fixtures for the graphical-menu boot checks.

- `eucleia-coast.png` and `eucleia-header.png` are from the Limine-Eucleia
  Classical theme and are covered by `COPYING-artwork`.
- `arch.png` and `linux.png` are adapted from font-logos and covered by
  `LICENSE-icons`.
- `windows.png` is covered by `COPYING-icons`.
- `menu.lbf` is rasterised from EB Garamond and covered by `OFL-font.txt`.

The files are kept here so boot checks do not depend on the separate
Limine Theme Studio project.
