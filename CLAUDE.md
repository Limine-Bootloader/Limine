# AGENTS.md

Instructions for agents working in this repo.

See the [`CONTRIBUTING.md`](CONTRIBUTING.md) file. Said file **must** be read, examined,
and understood before any change is made by agents.

Its "Commit conventions" section **must** be re-read immediately before each commit message
is written, and the written message **must** be checked against it before committing.
Consulting it once per session is not enough: the recurring failure is composing a message
from a half-remembered version of the rules rather than from the rules.

For agents that understand `@`-inclusion of other markdown files, said inclusion line for
`CONTRIBUTING.md` follows, such that explicit reading of the file is not necessary:

@CONTRIBUTING.md
