# AGENTS.md

Instructions for agents working in this repo.

See the [`CONTRIBUTING.md`](CONTRIBUTING.md) file. Said file **must** be loaded, examined,
and understood before any change is made by agents.

Adding to `CONTRIBUTING.md`, a few agent-specific rules:

- For agent-made commits, add an `Assisted-by:` trailer (after a blank line) naming the model
  (e.g. `Assisted-by: Claude:claude-opus-4-8`).
- Do not add `Co-authored-by:` (or other authorship) lines for agent work; the `Assisted-by:`
  trailer already covers it.
